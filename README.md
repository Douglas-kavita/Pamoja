# Pamoja

Mobile-first organization accountability platform for churches, chamas, SACCOs, investment groups, welfare groups and other member organizations.

Pamoja does not hold members' money. The organization's authorized bank or M-Pesa account remains the source of truth. The platform provides public discovery, private membership, personal contribution views, group ledgers, chat, voting, approvals and audit records.

## Deploy on Vercel

Import this repository into Vercel and deploy with the default settings.
